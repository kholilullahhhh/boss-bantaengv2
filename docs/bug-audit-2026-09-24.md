## Explicit non-findings (verified OK)

- Login rate limit 5 / 15 min / IP; blocked before password check; reset on success (`src/lib/rate-limit.ts`, `auth.ts`).
- `safeCallbackUrl` rejects open redirect (`//`, external, nested login).
- Upload route own auth + rate limit; middleware matcher excludes `/api`.
- Dual RBAC: middleware + `requireActionAuth` / `requireRouteAccess` — both kept.
- Owner always from `session.user.id` / `existing.userId` — never client body.
- Dashboard/list queries: `count`+`findMany` in `Promise.all`; take/skip; narrow `select`; no N+1 loops (groupBy + one raw monthly SQL).
